## 一、新增功能

### 1. 内网数据开放接口（8/31 ~ 9/2，共 4 个 commit 迭代）

**主接口 `GET /api/follow/open/videos`**（免登录，内网系统拉数用）：
- 19 字段全量返回：博主四件套（昵称/抖音号/secUid/数字ID）+ 视频标题/视频ID + 五项统计（播放/赞/评/分享/收藏）+ 来源类型 + 双时间 + 库内ID + **内网免登录播放直链 lanPlayUrl** + 抖音原链 + CK名称 + 字幕全文
- 多维度筛选：博主（ID精确/昵称模糊）、标题关键词、**同步日期区间**、发布日期区间、五项统计各自 min/max 区间、来源类型、排序（syncTime/createTime/digg/play/collect 倒序）
- **默认每页 100 条**（按同步时间从近到远），翻页传 `pageIndex`，全量显式 `pageSize=0`（上限 500）
- `withSubtitle=true` 才返回字幕全文（默认不读盘，保证速度）
- 字幕读取异步化——修复 3 人并发全量 75s 的性能问题（现全量 <1s）

**附录接口 `GET /api/follow/open/uperids`**：457+ 博主清单（昵称/ID/抖音号/secUid/同步开关/最后同步时间）

**配套文档** `docs/api-open-guide.md`：19 字段说明、14 个筛选参数表、9 个调用示例（curl + Python 通用格式）、FAQ

### 2. 博主身份字段落库（8/31）

- 视频表新增 `AuthorSecUid`/`AuthorDouyinNo` 两列（CodeFirst 自动建列）
- 入库时随取数响应直接写入——**喜欢/收藏来源**（作者不在关注表）也能有 secUid
- 抖音号三级回落：响应 short_id → followed 参数 → 查关注表（列表接口 short_id 实测恒 null，仅 detail 接口返回）
- 存量 4718 条回填 100%（join 关注表 + detail 接口补齐 39 个未知作者）

### 3. 前端页面新增列（8/31）

同步记录页（RecordTable）：
- 博主列后加「**抖音号**」（纯文本）「**SecUid**」（截断显示 + hover 全文 + 点击复制）
- 视频标题后加「**视频ID**」（完整显示 + 点击复制）
- 与内网接口、飞书表三处字段顺序一致

### 4. 飞书多维表格增强（9/1）

- 推送表新增 3 列：**抖音号 / SecUid / 视频ID**（文本列），18 列全量
- 老表自动补列机制扩展（重推旧表自动补缺列）
- **建表列序对齐抖小云页面**：博主后跟抖音号/SecUid、标题后跟视频ID（9/1 表已删旧重推生效；飞书 API 不支持移动已有列，旧表改序需删表重推）

### 5. ASR 字幕补漏扫描（8/27）

- `Video file not found.`/`no video file` 终态的视频，**文件恢复后自动清标记重转**（实测 2 分钟内接手）
- ASR 转写失败有限重试（3 次）
- 手动生成与队列转写按视频 ID 互斥（防同一视频并发转写）

### 6. 视频统计回填（8/26 已有，8/29 增强）

- 每天 05:30 刷新「关注来源 + 发布≤3天」视频的五项统计并回写飞书
- 8/29 起改 5 列局部更新（防覆盖字幕列）

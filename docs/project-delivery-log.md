## C. 每版功能变化详情

### 批次 0：上游基线 beta_2.2.0（≤2026-06-16）

- **边界依据**：上游最后提交 `c5922f9`(2026-06-16)；`appsettings.json` tagName。
- **能力**（平台原生，来源=上游）：Vue3 前端、.NET6 同步引擎（关注/喜欢/收藏/合集/短剧，Quartz）、SQLite+SqlSugar、Docker 容器化、H264/265 编码选择、NFO 生成、Quartz 持久化。
- **本项目动作**：本地镜像化（`dysync:asr-local`，docker commit 固化）。**功能贡献：无（上游）**。
- **遗留**：后续多批 bug 的温床（分页基准、日期筛选等均为此期代码）。

### 批次 1：ASR 集成 + 统计/导出（2026-08-11 ~ 08-15）｜来源：二次开发

- **新增**：本地 ASR 字幕集成（`fdb2ca4`）→ 同步记录页字幕生成/查看 UI（`14669f5`）→ 纯文本分行+复制（`641c26c`）；视频五项统计建模落库（`5d9a278`）；当天数据 Excel 导出（`9f40d04`，零依赖）；ASR 按需拉起（`59f2c01`）；独立 ASR 服务 D:\ASR-For-Dysync（复制配置化+任务看板，ASR仓 `639b3ea`~`232ee5b`）。
- **修复**：收藏路径/DLL拷贝/RecordTable GBK 编码损坏（`589c49f`）。
- **验证**：字幕内容接口实测（210字纯文本）；ASR 便携包整机冒烟。证据：specs `2026-08-13/15-*` 4份。
- **周会摘要**：给抖小云接上自建 Whisper 字幕服务，同步页可生成/查看字幕；视频播放/点赞等五项统计入库并可导出 Excel。
- **贡献**：AI 辅助开发为主（用户批准设计）。

### 批次 2：飞书推送体系（2026-08-21 ~ 08-24）｜来源：二次开发

- **新增**：每日定时推送多维表格（13列）；OAuth 用户身份强制（方案B，`a1719a2`）；字幕等待推送（10分钟重查/5h保险丝/ASR告警 `21872c0`）；五项统计每日 05:30 回填+回写飞书原表（`557bda1`/`f2087f5`）；ASR 回扫窗口可配（`754d020`）；播放链接+内网播放列（`aff6a49`/`f5a0617`）。
- **修复**：重复 Base（`42acdf4`）、20029 授权失败三根因、回调 localhost→127.0.0.1（`3f17d77`）、XSS 防护（`bf2d6e6`）。
- **验证**：配置指南 `docs/feishu-app-setup.md`；8/25 实推 30 条成功（库记录核实）。
- **周会摘要**：抖音同步数据每晚自动进飞书多维表格（含字幕全文与播放链接），统计每天自动刷新回写。
- **部署**：本机镜像 `808cfc23` 时代；NAS 场景方案文档定稿（`deploy-nas-2026-08-24.md`）。

### 批次 3：ASR 异步队列（2026-08-24）｜来源：二次开发

- **新增**：`SubtitleQueueJob` 扫库消费队列（`728c147`）；实体 3 列+五态判定；前端条件轮询+看板队列格（`4596c45`）；ASR 侧落盘恢复/幂等/doing自愈（ASR仓 `6261c2c`）。
- **效果（实测记录）**：同步入库从阻塞 1 小时级变秒级；容器重启续写、404 幂等重报均 E2E 通过（specs `2026-08-24-asr-queue-*`）。
- **周会摘要**：字幕转写改异步队列，同步不再被长视频卡住，断电断网可自愈。

### 批次 4：双链路稳定性修复（2026-08-26 ~ 08-29）｜来源：二次开发

- **修复（高危）**：token 并发刷新互斥、pushDate 跨午夜快照、Base 探活误重建、字幕队列 9 处 stale 覆盖（`8c63503`~`039ead3`）；复审二批 6 项：token 锁 static 化、config 列级回写、AutoGenSubtitle 门槛、标记窗口含昨天、统计 5 列局部更新（`b286b9b`）；网络异常分型 `DouyinNetworkException`（`43e96ea`）。
- **修复（前端）**：follow 页分页基准（`ca4e106` 前）、日期筛选同一天返回 0 条。
- **新增**：ASR 补漏扫描（文件恢复自动重转）、失败有限重试、手动/队列互斥（`a2136d2`~`bfaa545`）。
- **验证**：全部 E2E（补漏扫 2 分钟实测等）；arm64 tar 0828/0829 产出，QEMU 冒烟。
- **周会摘要**：ASR+飞书全链路代码审查修复 17 项缺陷，含并发 token 互斥、跨午夜推送、字幕列覆盖等高危项；同步接口网络抖动不再误报 Cookie 失效。
- **事故**（同批期内，8/31 实际发生但归此教训）：宿主热写 SQLite 致库损坏，4718 行全部抢救恢复——沉淀「写库必先停容器」铁律。

### 批次 5：开放接口与博主身份（2026-08-31 ~ 09-01）｜来源：二次开发

- **新增**：免登录接口 `open/uperids`/`open/videos`（`e789837`/`35b56f8`）；多维筛选+分页+排序（`11cda72`）；视频表 AuthorSecUid/AuthorDouyinNo 落库+三级回落+存量 100% 回填（`1cf0ce3`）；前端抖音号/SecUid/视频ID 三列（`8eed323`/`b40395a`）；飞书表 18 列+列序对齐（`2d38586`/`0f58401`）；tag 空值 text_extra 回落+581 条回填（`bebebbf`）。
- **验证**：接口全参数 E2E；飞书 9/1 表 18 列实查确认；arm64 0902 tar QEMU 冒烟。
- **周会摘要**：内网系统可通过免登录 API 拉取全部同步数据（含博主 secUid/抖音号、播放直链、字幕），飞书表同步增加到 18 列并与页面列序一致。
- **发现（API 硬限制）**：飞书不支持移动已有列，改序=删表重推。

### 批次 6：接口定型与文档（2026-09-02 ~ 09-03）｜来源：二次开发

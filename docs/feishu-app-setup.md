# 飞书多维表格推送 — 配置指南与推送逻辑

> 目标：抖小云每天把同步的视频数据（含字幕）自动推到你自己飞书账号的多维表格里。
> 分两部分：**一、需要准备的配置**（一次性）**二、推送逻辑**（配置后全自动）。

---

## 一、配置准备（一次性，约 10 分钟）

### 1. 创建自建应用

1. 浏览器打开 [飞书开发者后台](https://open.feishu.cn/app) → 「创建企业自建应用」
2. 名称填「抖小云推送」（随意），创建后进入应用详情
3. 「凭证与基础信息」页复制 **App ID** 和 **App Secret**（待会儿填抖小云）

### 2. 开通权限（权限管理 → 搜索开通）

| 权限 | 说明 | 必需性 |
|---|---|---|
| `bitable:app` | 多维表格全套（建表/写数据） | **必需** |
| `drive:drive` | 云文档读写（建在你自己的文件夹需要） | **必需**（用户身份模式） |
| `offline_access` | 获取 refresh_token（授权长期有效） | **必需** |

### 3. 开启「网页应用」能力（OAuth 授权的前提）

1. 左侧「应用能力」→「网页应用」→ 开启
2. 桌面端主页填 `http://127.0.0.1:10101`（或你的访问地址），打开方式选浏览器
3. 保存

### 4. 配置重定向 URL（OAuth 回调）

1. 左侧「开发配置」→「安全设置」→「重定向 URL」→ 添加：
   ```
   http://127.0.0.1:10101/api/feishu/oauth/callback
   ```
2. ⚠️ **必须用 `127.0.0.1`，不能用 `localhost`**——飞书 OAuth 拒绝 localhost（配了也报 20029 重定向URL有误）
3. 从其他设备（局域网 IP）授权的话，把对应地址也加一条（支持多条）

### 5. 发布版本

「版本管理与发布」→ 创建版本 → 发布（个人版一般即发布即生效）。**权限、网页应用、重定向 URL 的改动都要发版才生效。**

### 6. 准备存放文件夹（Base 建在这里）

1. 飞书 → 云文档 → 我的空间 → 新建文件夹（如「抖小云数据」）
2. 打开文件夹，浏览器地址栏 `https://xxx.feishu.cn/drive/folder/xxxxxxxxxx`，**`folder/` 后那串就是文件夹 token**
3. 待会儿填进抖小云「文件夹token」——之后每月的多维表格都自动建在这个文件夹里，归属你自己

### 7.（可选）群机器人（推送结果/ASR 告警通知）

1. 飞书群 → 群设置 → 群机器人 → 添加机器人 → 自定义机器人
2. 复制 webhook 地址（`https://open.feishu.cn/open-apis/bot/v2/hook/xxx`）
3. 不配也能用，只是收不到「推送成功/失败」和「ASR 异常」通知

### 8. 填进抖小云并授权

1. 抖小云设置页 → 飞书推送区：
   - 打开「飞书推送」开关
   - 填 **App ID / App Secret / 文件夹token /（可选）群机器人 webhook**
   - 推送时间默认 **23:50**（可改）
   - 保存
2. 点「**授权飞书账号**」→ 新窗口登录飞书并点「同意」→ 看到「授权成功」页
3. 回设置页，授权状态变为「已授权（刷新凭证至 xxx）」
4. 点「**测试连接**」验证凭证 → 点「**立即推送今天**」验收：你的文件夹里应出现「抖小云同步数据-2026年8月」多维表格

## 二、推送逻辑（配置后全自动）

### 每天发生了什么

```
23:50 定时触发（或手动点「立即推送今天」）
  │
  ├─ 读取今天同步入库的全部视频（13 列：时间/博主/标题/统计/字幕全文…）
  │
  ├─ [仅定时] 字幕等待：今天的视频里还有字幕在转的？
  │     ├─ 有 → 推迟，每 10 分钟重查（期间探 ASR 健康，连续 2 次不通
  │     │        → 群告警一次；最多等到 04:50 强制推）
  │     └─ 全部完成（或失败终态）→ 继续
  │     （失败的视频不阻塞推送，字幕列为空照推）
  │
  ├─ 定位/创建本月多维表格「抖小云同步数据-2026年8月」
  │     └─ 建在你的文件夹里，归属你自己（9月自动建新表进同一文件夹）
  │
  ├─ 定位/创建今天的日期表「8月23日」（13 列）
  │
  ├─ 清空该表 → 重新写入今天全部数据（幂等：重复推送不产生重复行）
  │
  ├─ 群机器人通知推送结果（已配 webhook 时）
  │
  └─ 设置页「推送状态」记录结果（如「2026-08-23 23:51 成功 12条」）
```

### 身份与授权（为什么需要「授权飞书账号」）

- 推送以**你本人的身份**执行（OAuth 用户授权）——所以多维表格建在**你的**文件夹、归属是你、我的空间直接可见
- 授权一次后长期有效：每天推送时自动续期（refresh token 滚动更新，有效期 7 天，每天推就永不过期）
- **超过 7 天没推送**（如长期停机）或你修改飞书密码/取消授权后，需要重新点一次「授权飞书账号」
- 未授权时推送走应用身份（表格建在应用空间，需要链接访问）——功能可用但体验差，推荐始终授权

### 字幕等待规则（详细）

| 视频 subtitle 状态 | 定时推送行为 |
|---|---|
| 已生成字幕 | 正常推 |
| 转换中/待转换 | **等待**（整个推送推迟，10 分钟/轮重查） |
| 转换失败（终态） | 不等待，字幕列空着照推 |

- 手动点「立即推送今天」**从不等待**，点了立即推当前状态
- ASR 服务不可用时：群告警一次 + 推送继续等（ASR 恢复转完自然推）
- 保险丝：最多等到次日 04:50，无论如何都会推送当天数据

### 每月/每天的表格结构

```
📁 你的文件夹（抖小云数据）
 └── 📊 抖小云同步数据-2026年8月     ← 每月 1 个，自动创建
      ├── 8月1日                    ← 每天 1 张，自动创建
      ├── 8月2日
      └── …
```

日期表 13 列：同步时间 / 发布时间 / 同步类型 / 博主 / 视频类型 / 视频标题 / CK名称 / 播放 / 点赞 / 评论 / 分享 / 收藏 / 字幕全文

### 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 授权时报 20029「重定向URL有误」 | ① 重定向 URL 必须是 `127.0.0.1` 不是 localhost；② 检查网页应用能力已开启；③ 改动后要发布版本 |
| 授权失效提示 | 超 7 天未推送或取消过授权 → 重新点「授权飞书账号」 |
| 推送结果「请填写文件夹token」 | 用户身份模式必须填你自己的文件夹 token（地址栏 folder/ 后那串） |
| 推送结果「ASR 不可用」 | 字幕等待中 ASR 挂了 → 检查 ASR 服务（通常重启 watcher：`Start-ScheduledTask -TaskName DysyncAsrWatcherRun`） |
| 当天表格数据不全 | 字幕在转/等待超时强推 → 数据和字幕次日推送会自然补齐（清空重写幂等） |
| 想立即看到完整数据 | 修复问题后手动点「立即推送今天」（会重写当天表） |
